## 🛠️ Stack Tecnológica

### Backend
- **Java** - Linguagem principal do backend
- **Spring Boot** (sugestão) - Framework para APIs REST

### Banco de Dados
- **MongoDB** - Banco de dados NoSQL para armazenamento dos dados

### Frontend
- **Biblioteca de componentes pronta** - UI components para agilizar o desenvolvimento
  - Sugestões: Material UI, Chakra UI, Ant Design, ou similar

### Pagamentos
- **Ambiente de testes (sandbox)** - Integração com gateway de pagamentos em modo de desenvolvimento
  - Sugestões: Stripe (test mode), Mercado Pago (sandbox), ou similar

## 📁 Estrutura do Projeto

```
Pede-Ai/
├── backend/          # Código Java (Spring Boot)

├── docs/             # Documentação do projeto
└── README.md         # Este arquivo
```

## 🚀 Como Rodar

### Backend
```bash
cd backend
# Configure suas variáveis de ambiente (MongoDB, etc.)
mvn spring-boot:run
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
